# Contributing

Thanks for helping improve KSA Cinematic Tools.

1. For a bug report, include your MTA version, the command and arguments, expected and actual behavior, and a sanitized server log excerpt.
2. Keep pull requests focused. Preserve Admin-only authorization and do not include databases, account details, server passwords, private IPs, maps, or proprietary GTA assets.
3. Check startup, object and NPC persistence, export, account skin handling, and resource restart on a separate test server. State clearly what you could not test.
4. Do not replace the third-party object catalog without checking its license and maintaining attribution.

See [docs/manual-testing.md](docs/manual-testing.md) for the release checklist.
